# IT Admin Script Pack

Three battle-tested PowerShell scripts for Windows sysadmins.

| Script | Purpose |
|---|---|
| Get-StaleADAccounts.ps1 | Find/disable inactive AD users |
| Get-DiskSpaceReport.ps1 | HTML disk report across servers |
| Remove-OldProfiles.ps1 | Clean up old local profiles |

Always test with `-WhatIf` first. MIT-style personal/commercial use license; no redistribution of the pack itself.
